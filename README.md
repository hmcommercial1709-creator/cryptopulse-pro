# CryptoPulse Pro

Telegram-first crypto market intelligence and trading assistant.

## Initial architecture
- Telegram Bot API integration
- Market data and alerts
- User preferences and subscription layer
- Telegram Stars payment scaffolding
- Secure environment-based configuration

## Safety
CryptoPulse Pro provides market information and trading tools. It does not promise guaranteed profits or store exchange private keys in source code.

## Configuration
Copy `.env.example` to `.env` and provide the required credentials locally or through the deployment platform's secret manager.
